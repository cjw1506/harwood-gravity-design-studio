After importing into WordPress

  1. Import the Gravity Forms JSON file.
  2. Embed the form using the form block and select either Orbital or Gravity 2.5 consistently.
  3. The exported form contains one hidden “Harwood Studio styling” HTML field that carries scoped CSS.
  4. Publish the page, then compare desktop and mobile views. Theme fonts loaded outside the form can still differ unless the same font is available in both places.
