# Harwood Gravity Forms Design Studio

A private, browser-based design studio for styling Gravity Forms and creating staff notifications, patient confirmations, and on-screen confirmation messages.

## Run locally

Open `index.html` in a modern browser. The application has no build step, backend, external dependencies, analytics, or network requests.

## Privacy

Imported form definitions and saved design settings remain in the browser's local storage. Do not use real patient data in previews.

## Deployment

This is a static site. Deploy the repository root to any static hosting service with no build command and `/` as the output directory.
